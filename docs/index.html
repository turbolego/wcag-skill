Interactive, local-first examples

See accessibility fixes in action

Compare intentionally flawed examples with improved implementations. Each example explains the user impact and lets you try the change with a pointer or keyboard.

These examples are demonstrations, not a conformance claim. WCAG 2.2 AAA includes every applicable Level A and AA criterion as well as AAA. A real audit must cover the complete site, all relevant states, and assistive technology. WCAG 4.1.2 is Level A and is shown because it is inherited by an AAA target.

How the WCAG skill approaches a fix

  1. 1. InventoryIdentify routes, controls, states, and applicable criteria.
  2. 2. ImprovePrefer native HTML and repair names, roles, values, and interaction.
  3. 3. VerifyRun automated checks plus focused keyboard and state tests.
  4. 4. RecordKeep evidence and human-review items; do not overclaim.

See the skill workflow, AAA evidence matrix, and manual test protocol.
